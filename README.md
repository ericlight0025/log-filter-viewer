# Log Filter Viewer 🔍

> **零依賴、純前端的單一 HTML 日誌過濾檢視器 (Single-file HTML Log Filter Viewer)**  
> 專為開發者、SRE、DevOps 設計。解決傳統文字編輯器看大量 Log 時「搜尋關鍵字看不到前後文」以及「前後文重疊時行數重複印出」的痛點。

---

## ✨ 核心特色

1. **🚀 零依賴、純本機執行**
   - 僅使用原生 HTML、CSS、Vanilla JavaScript，不需要 Node.js、npm、Python 或任何後端伺服器。
   - 下載單一 `index.html`（或 `log-filter.html`），雙擊即可在任何瀏覽器秒開。
   - 所有 Log 都在本機瀏覽器內解析，敏感資訊絕不外流。

2. **➕ 多關鍵字搜尋 (OR / AND 條件)**
   - 點擊 `➕` 可動態新增多組關鍵字，每組均有獨立色彩標記。
   - 支援 **符合任一 (OR)** 與 **符合全部 (AND)** 邏輯切換。
   - 不區分大小寫（Case-insensitive contains）。

3. **🕒 精確至秒的時間區間過濾**
   - 載入 Log 時自動解析時間戳記，預先填入檔案的最早與最晚時間。
   - 支援標準 ISO、常見日誌格式與 Java Log4j 毫秒逗號格式（`yyyy-MM-dd HH:mm:ss,SSS`）。
   - 遇到無時間戳記的行（如 Java Exception Stack Trace），自動智慧繼承上一筆時間。

4. **🧠 智慧上下文區間合併（前後 N 行不重複）**
   - 支援自訂前後上下文（±0、±3、±5、±10、±20、±50 行）。
   - **重疊區間自動 Merge**：當第 100 行與第 103 行皆命中時，自動合併為單一區間，**同一行號在畫面上最多只會出現一次**。

5. **🛡️ 終極安全高亮（Anti-Entity Splitting）**
   - 徹底解決傳統 Regex 置換導致 HTML 實體（如 `&amp;`、`<`）被切斷破圖的問題。
   - 命中行（Match）與上下文行（Context）具有不同底色區隔。

6. **📋 一鍵複製純文字**
   - 點擊「📋 複製結果」即可將過濾後的結果（含對齊行號與區塊分隔線）複製至剪貼簿，方便直接貼到 Slack 或 Issue 追蹤系統。

7. **💾 查詢條件匯出與匯入 (Presets)**
   - 可將關鍵字組合、條件、時間區間打包匯出為 JSON 設定檔。
   - 團隊成員可直接匯入設定檔，快速重現除錯查詢條件。

8. **📂 支援拖曳上傳 (Drag & Drop)**
   - 直接將 `.log` 或 `.txt` 檔案拖入視窗即可開始分析。

## 🖥️ 畫面預覽

```text
+--------------------------------------------------------------------------+
| 📋 Log Filter Viewer                                                     |
+--------------------------------------------------------------------------+
| 📂 選擇 Log 檔案   sample-server.log | 共 248 行   [💾 匯出條件] [📂 匯入條件]   |
|                                                                          |
| [#1] [ ERROR        ] ✕   [#2] [ timeout      ] ✕   [➕ 新增關鍵字]        |
| 條件: [符合全部(AND) ▼]   [✔] 時間過濾: [ 00:00:01 ] ～ [ 00:03:00 ]   [↺]   |
|                                                                          |
| [🔍 搜尋]  [清空條件]   前後: [±5行 ▼]               符合: 3 行  [📋 複製結果] |
+--------------------------------------------------------------------------+
| Line | Log                                                               |
|  100 | 2026-09-24 00:01:08 INFO  Processing request                      |
|  101 | 2026-09-24 00:01:08 ERROR Failed to create order: timeout         |
|  102 | 2026-09-24 00:01:08 ERROR PSQLException: Connection timed out     |
+--------------------------------------------------------------------------+
```

## 🚀 快速上手

1. Clone 本專案：
   ```bash
   git clone https://github.com/ericlight0025/log-filter-viewer.git
   ```
2. 直接使用瀏覽器開啟 `index.html`（或 `log-filter.html`）。
3. 載入專案內附的 `sample-server.log` 範例檔案即可進行功能測試。
